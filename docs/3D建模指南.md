# Pocky 3D 化指南

> 目标：从"抽象 2D 卡通"升级到"真正的 Pocky"。
> 先说结论：**走双线**——
> **B 线（主线）**：照片 → AI 生成 3D 模型 → 绑骨动画 → 进桌宠，他能动、能互动；
> **A 线（并行）**：手机扫描 3D Gaussian Splatting，照片级真实的"数字雕像"，最像本人但基本不能动。
> 两条线用的是同一批照片素材，先拍素材，两边同时推进。

---

## 一、四条路线对比

| 路线 | 像不像本人 | 能否动画 | 成本 | 周期 | 结论 |
|------|-----------|---------|------|------|------|
| A. 手机扫描（3DGS/NeRF） | ★★★★★ 照片级 | ❌ 基本静态 | 免费 App | 1 天 | 做珍藏版，必做 |
| B. AI 照片生成 3D | ★★★☆ 明显是他，卡通-写实之间 | ✅ 可绑骨 | 免费额度～百元订阅 | 2–7 天 | **主线，进桌宠** |
| C. 找建模师定制 | ★★★★☆ 取决于预算 | ✅ 专业动画 | ¥1000–5000+ | 2–6 周 | B 线效果不满意再上 |
| D. 自学 Blender 手工建模 | 上限最高 | ✅ | 时间成本极高 | 数月 | 除非想入坑建模 |

### 先建立现实预期（很重要）

- Pocky 是**长毛蓬毛犬**。实时渲染里"逐根毛发"连 3A 游戏都很难做，桌宠/网页里的 3D Pocky 会是
  **"毛茸茸质感的贴图表面"**——看起来毛绒绒，但不是真毛发。
- 观感上**最接近真实 Pocky** 的是 A 线的 3DGS 扫描（它直接重建照片里的光影和绒毛感），
  代价是它像一座可以 360° 环绕观看的"雕像"，做不了走路摇尾巴。
- 所以双线互补：B 线给你一只**会动的、明显是 Pocky 的 3D 宠物**，A 线给你一份**照片级真实的数字存档**。

## 二、第一步：拍素材（两条线共用，本周末就能做）

### 给 B 线（AI 生成）的照片 —— 关键是"多角度、全身、干净背景"

趁他站着或坐着不动时拍，每个角度 2–3 张：

- [ ] **正侧面全身**（最重要，AI 主要靠这张定体型）
- [ ] 正面全身
- [ ] 背面全身（拍到卷尾巴的形态）
- [ ] 前 3/4 视角（脸和身体都能看到）
- [ ] 头部特写（正面 + 侧面）

要求：白天散射光（阴天或窗边最好），避免逆光和强影子；背景尽量干净（纯色墙/地板前）；
狗占画面主体；不要用广角端拍（变形）。

### 给 A 线（扫描）的素材 —— 关键是"他不动、你绕圈"

趁他**熟睡**时：

- [ ] 手机绕他缓慢转 2–3 圈（高、中、低三个高度各一圈），拍 1–3 分钟视频或 100–200 张连拍
- [ ] 光线均匀、别开闪光灯、动作慢（防模糊）

### 顺便录（给桌宠用）

- [ ] 叫声、哼唧、打呼 → 放进 `desktop-pet/renderer/assets/bark.mp3` 立刻生效

拍好的素材都丢进 `data/photos/`、`data/videos/`、`data/sounds/` 归档。

## 三、B 线操作步骤（主线：可动画的 3D Pocky）

### 第 1 步：照片 → 3D 模型

任选一个（都支持图片输入、都有免费额度，建议都试一遍取最像的）：

| 工具 | 说明 |
|------|------|
| [Tripo3D](https://www.tripo3d.ai) | 质量稳定，支持多视角图输入，**自带四足自动绑骨+动画**，一站式最省事 |
| [Meshy](https://www.meshy.ai) | 贴图效果好，有动画库 |
| [Rodin / Hyper3D](https://hyper3d.ai) | 写实向效果强 |
| [腾讯混元 3D](https://3d.hunyuan.tencent.com) | 免费，中文界面，开源可本地跑 |

操作：上传正侧面 + 正面 + 背面照片（多视角模式）→ 生成 → 挑最像的一版 →
导出 **GLB 格式**（带贴图）。

生成不像怎么办：换主图重试（正侧面全身那张最关键）、把背景抠掉再传、
或在 prompt 里补充特征描述（cream white fluffy spitz dog, apricot ears and back, curled fluffy tail）。

### 第 2 步：绑骨 + 动画

- **用 Tripo 的话**：生成后直接点 Auto-Rig（四足）→ 套用走/跑/坐等动画预设 → 导出带动画的 GLB，一站搞定
- **其他工具生成的**：把 GLB 传到 [Anything World](https://anything.world)（Animate Anything 功能，
  专做四足动物自动绑骨），得到带走路/跑/坐动画的模型
- 需要的基础动作：**idle（站立呼吸）、walk、sit、lie、sleep**，有 run 和 wag 更好

### 第 3 步：本地预览

```bash
cd viewer
npm install
npm start        # 打开 http://localhost:8788，把 GLB 拖进去
```

能看到模型和动画列表，转一转看像不像、动画顺不顺。

### 第 4 步：进桌宠

把选定的模型放到 `desktop-pet/renderer/assets/pocky.glb`，然后把文件发到对话里说一声——
我来做 three.js 集成：透明窗口里实时渲染 3D Pocky，把大脑的动作指令
（sit/shake/walk/sleep…）映射到模型动画，现有的行为引擎、记忆、聊天大脑全部不变。

## 四、A 线操作步骤（照片级数字存档）

1. 手机装 **Luma AI**（推荐）/ Polycam / KIRI Engine / Scaniverse 任一
2. 用上面拍好的环绕视频/连拍导入，选 3D Gaussian Splatting（或 NeRF）模式重建
3. 得到可 360° 观看的照片级 Pocky，可以：
   - 导出旋转视频（发朋友圈/留存）
   - 导出 splat/ply 文件归档到 `data/scan/`（未来技术升级了还能重新利用——
     dynamic 3DGS 让扫描"动起来"的研究正在快速进展，原始素材最值钱）
